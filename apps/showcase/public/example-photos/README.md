On October 22, 2026, Reuters listings showed different ongoing editorial options from US$175 to US$262 per image.
Those options have different reuse limits.
Two images at those rates would cost US$350 to US$524, before any tax.
This range is a planning estimate, not a confirmed quote for this project.
The live checkout could not be verified.

The [Reuters license terms](https://www.reutersconnect.com/transactional-license-terms/) limit publication, reuse and distribution.
An editorial web license does not establish permission to distribute source photographs in this public repository.
Confirm the intended design-system use before a purchase.

Use these details in a license inquiry:

- Public Storybook and Showcase sites for an open-source component library.
- Repeated display in component examples, on desktop and mobile.
- Public GitHub source files, forks and screenshot baselines.
- Worldwide access, with no planned end date.
- Cropping, resizing and required photo credits.
- Separate photo terms from the MIT software license.

If the license excludes public source files, keep the purchased files outside Git.
Confirm permission for the hosted display and screenshots separately.
Record the approved uses and required credits before deployment.
Do not publish private receipts or personal account details.
