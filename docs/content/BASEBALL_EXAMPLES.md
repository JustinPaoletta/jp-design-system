# Baseball examples

Storybook and Showcase use one fictional baseball setting.
The Riverton Falcons play the Lakeview Bears.
All names, records, scores and events are sample data.

## Game examples

The October 11 game ends with the Falcons winning 5–3.
The Falcons have nine hits and no errors.
The inning chart shows cumulative runs through nine innings.
The next game is October 12 at 18:30 at Riverton Field.

Season charts compare Falcons and Bears runs by month.
Large tables contain additional fictional league players.
Practice examples use batting, pitching and fielding drills.
Clock-change examples use field checks to show repeated local times.

## Component examples

Use the same names and terms in related examples.
Keep the component names in the Storybook navigation.
Use baseball copy for visible example data, labels, hints and messages.
Keep standard control actions, such as Save, Cancel and Retry, clear.
Use component inputs for example-specific copy.
Update selectors and visual baselines when the example text changes.

The library's generic control defaults remain available to other applications.
